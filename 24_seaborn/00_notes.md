# Seaborn Notes

A topic-by-topic guide to Seaborn. The original explanations, comparisons, and useful examples are retained; exact repeated plot snippets within a topic link back to their first example. The complete EDA walkthrough remains self-contained.

| Topic | Coverage |
| --- | --- |

| [Categorical Plots](03_categorical_plots.md) | Counts, estimates, boxplots, and violin plots |
| [Categorical Relationship Plots](04_categorical_relationships.md) | Strip/swarm plots, `catplot()`, and category ordering |
| [Regression Plots](05_regression_plots.md) | Regression lines, confidence intervals, and `lmplot()` |
| [Multivariate Visualization](06_multivariate_visualization.md) | `pairplot()`, `jointplot()`, correlation, and heatmaps |
| [Styling & Customization](07_styling_and_customization.md) | Themes, palettes, labels, legends, and saving |
| [Faceting & Plot Grids](08_faceting_and_grids.md) | `FacetGrid`, `PairGrid`, and faceting patterns |
| [Matplotlib Integration](09_matplotlib_integration.md) | Figures, axes, subplots, and annotations |
| [Complete EDA](10_complete_eda.md) | End-to-end exploration workflow and cheat sheet |

## Suggested learning order

Start with the fundamentals, then study the plot families. Finish with styling, faceting, Matplotlib integration, and the complete EDA example.
