# Python Keywords

Keywords are reserved words in Python that have special meanings and cannot be used as variable names, function names, or any other identifier.

## What Are Keywords?

Python has a set of built-in keywords that are used to define the structure and logic of a program. These words are part of the language itself.

For example:

```python
if
else
for
while
def
class
True
False
```

## Why Keywords Matter

Keywords help Python understand the code you write. They are used for:

- decision-making
- looping
- functions
- classes
- logical operations
- exception handling

If you use a keyword as a variable name, Python will raise an error.

## Examples of Common Keywords

### `if`, `elif`, `else`

Used for conditional statements.

```python
age = 18

if age >= 18:
    print("Adult")
else:
    print("Minor")
```

### `for` and `while`

Used for loops.

```python
for i in range(3):
    print(i)
```

```python
count = 0
while count < 3:
    print(count)
    count += 1
```

### `def`

Used to define a function.

```python
def greet():
    print("Hello!")


greet()
```

### `class`

Used to define a class.

```python
class Student:
    pass
```

### `True` and `False`

Used for boolean values.

```python
is_active = True
is_logged_in = False
```

### `and`, `or`, `not`

Used for logical operations.

```python
x = 5
print(x > 3 and x < 10)
print(x > 10 or x < 3)
print(not (x == 5))
```

## Important Rule

You cannot use Python keywords as variable names.

Example:

```python
# This is invalid
for = 10
```

This will cause a syntax error because `for` is a reserved keyword.

## Listing Python Keywords

You can view all Python keywords in your environment using:

```python
import keyword
print(keyword.kwlist)
```

This will print a list of all reserved keywords.

## Example Program Using Keywords

```python
age = 20

if age >= 18:
    print("You are eligible.")
else:
    print("You are not eligible.")
```

Output:

```python
You are eligible.
```

## Summary

Python keywords are reserved words with special meanings. They help define the structure of the language, and you should avoid using them as variable names or function names.
